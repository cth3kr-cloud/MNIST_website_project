## 2026-11-04

### Commit
- **브랜치**: feature/ai-model
- **메시지**: chore(ai): 기본적 MNIST 인공신경망 구현 
- **변경 사항**:
  - NumPy를 활용하여 MNIST 손글씨 숫자 분류를 위한 다층 퍼셉트론(MLP) 구조를 설계함.
  - 입력층(784개), 은닉층(128개), 출력층(10개)으로 구성하고 ReLU와 Softmax 활성화 함수를 적용함.
  - Cross Entropy 손실 함수와 Gradient Descent를 이용한 학습 과정을 구현함.
  - 순전파, 역전파, 가중치 및 편향 업데이트 과정을 함수별로 분리함.
  - Mini-batch 학습 방식을 적용하여 여러 데이터를 묶어 학습하도록 구성함.
  - 학습된 가중치와 편향을 저장하고 추후 예측 과정에서 활용할 수 있도록 구성함.
- **의사결정**:
  - 데이터 전처리는 데이터 담당 팀원이 Pandas를 활용하여 진행하고, AI 모델은 전달받은 NumPy 배열을 입력으로 사용하도록 역할을 분리함.
  - AI 모델 내부의 신경망 연산은 외부 딥러닝 라이브러리 없이 NumPy만으로 직접 구현하기로 결정함.
  - 모델 구조는 구현 및 수학적 원리 이해를 고려하여 은닉층 1개를 갖는 MLP로 설정함.
- **배운 점**:
  - 순전파 과정에서 행렬 곱셈을 통해 여러 뉴런의 연산을 효율적으로 수행하는 원리를 이해함.
  - Softmax와 Cross Entropy의 결합 미분 결과가 예측값과 정답값의 차이로 나타나는 이유를 학습함.
  - 역전파 과정에서 연쇄법칙을 적용하여 각 층의 가중치와 편향에 대한 gradient를 계산하는 원리를 이해함.
  - 가중치의 gradient는 입력값과 오차의 곱으로, 편향의 gradient는 오차의 합으로 계산되는 이유를 이해함.
  - Mini-batch 학습에서 여러 데이터의 gradient를 평균내어 파라미터를 업데이트하는 과정을 학습함.
- **비고**:
  - 데이터 담당 팀원과 입력 데이터의 변수명 및 배열 형태를 공유할 필요가 있음.
  - 실제 MNIST 데이터와 연결한 학습 및 정확도 검증이 필요함.
  - 학습된 모델을 FastAPI 백엔드와 연결하는 작업은 추후 진행 예정.
